# Module 2 — Analytics Pipeline

## Overview

Module 2 is the analytics stage of the Zepto AI/ML Capstone Project.

This module uses the structured book data produced by Module 1 and performs analytical processing to identify patterns in categories, ratings, prices, rankings, and business-oriented insights.

The workflow is:

**Load Data → Analyse → Rank → Generate Insights → Save Results → Verify**

---

## Objectives

The main objectives of this module are:

- Load structured book data from the SQLite database created by Module 1
- Analyse book categories and category performance
- Analyse rating distribution
- Analyse book prices
- Identify the most expensive books
- Identify highly-rated books
- Identify affordable books
- Generate business-oriented insights
- Save analytical results as CSV files
- Verify the generated analytical outputs

---

## Data Source

Module 2 uses the structured data generated by **Module 1 — Data Pipeline**.

## Design Decisions

### Pandas

Pandas is used for the analytical workflow because structured catalogue data can be efficiently filtered, grouped, ranked, and analysed using DataFrames.

### Reusing Module 1 Data

The analytics module uses the SQLite database created by Module 1 rather than maintaining a separate dataset.

This keeps the three modules connected and ensures that the analysis is performed on the same cleaned and structured data.

### Business-Oriented Analysis

The analysis focuses on useful catalogue-level information such as category performance, ratings, prices, rankings, and business insights.
